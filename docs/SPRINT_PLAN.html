✅ كيف نتحقق
• شركة تطلب شحن مجمد بمحطتين → الطلب يُرسَل بحالة PENDING_PRICING للمشرف
• المشرف يراجع الطلب ويحدد السعر يدوياً → العميل يستلم عرض السعر بالإيميل
• العميل يوافق (CUSTOMER_CONFIRMED) أو يرفض (CANCELLED)

🔄 Order Status Flow الجديد
DRAFT → PENDING_PRICING → PRICED → CUSTOMER_CONFIRMED → ASSIGNED → IN_TRANSIT → DELIVERED
مسار الرفض: PRICED → CANCELLED (عند رفض العميل للسعر)
